# Vitalis brand

## Mark
A V on a rounded indigo tile; its right arm ends in a raspberry dot, the heartbeat.
The tile corner radius is 120/512 of the width.

## Colours
| Use | Light | Dark |
|---|---|---|
| Tile (indigo, sleep) | `#4C5BD4` | `#8E9BFF` |
| Dot (raspberry, heart) | `#D6336C` | `#FF6B8E` |
| V stroke | `#FFFFFF` | `#0E1424` |
| Wordmark ink | `#172033` | `#E7EBF3` |

## Type
Wordmark: Bricolage Grotesque Bold, lowercase "vitalis", tracking −3.5%. In `logo.svg` it is live
text with a system fallback (no outline converter was available); where the font can't load, use
the mark alone.

## Clear space and minimum size
- Keep clear space of at least 1/4 of the tile width on every side.
- Smallest size: 16 px for the mark. Don't use the lockup below 120 px wide.

## Which file where
| File | Use |
|---|---|
| `logo-icon.svg` | Default mark on light backgrounds |
| `logo-dark.svg` | Mark on dark backgrounds |
| `logo-mono.svg` | One-colour print or embossing (`currentColor`) |
| `logo.svg` | Mark + wordmark lockup |
| `favicon.svg`, `favicon-32.png` | Browser tab icon |
| `apple-touch-icon.png` | iOS home screen (180 px, square; iOS rounds the corners) |
| `icon-192.png`, `icon-512.png` | Web app manifest |
